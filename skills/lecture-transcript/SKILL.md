# Lecture Transcript — Транскрипт лекции → учебные материалы

## Описание

Сырой транскрипт лекции (ASR с ошибками, без структуры, с повторами) →
структурированный учебный материал заданного формата.

## Режимы

Режим указывается при вызове. Если не указан — `study_notes`.

### `study_notes` — Конспект
Структурированный конспект для подготовки к экзамену/зачёту.

Формат:
```
## Лекция: [тема]
## Преподаватель: [имя если есть]
## Дата: [если упоминается]

### Ключевые тезисы
- Тезис 1
- Тезис 2
- ...

### Конспект
#### [Подтема 1]
[текст с терминами жирным]
#### [Подтема 2]
...

### Термины и определения
- **Термин** — определение из лекции
- ...

### Концепции и модели
- **Концепция** — описание + связь с другими концепциями

### Формулы / схемы (если есть)
- Формула: ...
- Применение: ...

### Самопроверка
- [ ] Вопрос 1 по материалу лекции
- [ ] Вопрос 2
- ...

### Связи с другими темами
- Эта лекция связана с: [темы других лекций если упоминаются]
```

### `narrative` — Связный пересказ
Связный текст, пригодный для чтения как статья. Без markup-структуры, но с абзацами и логичными переходами.

Правила:
- Убрать повторы и оговорки преподавателя
- Восстановить логику повествования
- Сохранить терминологию курса
- Не добавлять外部 факты

### `review` — Аналитическое ревью
Критический разбор лекции:

```
## Ревью лекции: [тема]
### Основные аргументы
1. ...
### Сильные стороны
- ...
### Слабые стороны / спорные моменты
- ...
### Открытые вопросы
- ...
### Связь с литературой
- Что из лекции согласуется/расходится с известными подходами
```

### `terms` — Извлечение терминов
Только терминология:

```
## Термины лекции: [тема]
| Термин | Определение | Контекст употребления |
|--------|-------------|----------------------|
| ...    | ...         | ...                  |
```

### `flashcards` — Карточки для запоминания
Формат карточек:

```
## Карточки: [тема]

**Q:** Вопрос
**A:** Ответ (1-2 предложения)
**Source:** [абзац транскрипта]

---
```

### `exam_prep` — План ответа к экзамену
Подготовка к устному/письменному экзамену:

```
## Вопрос: [сформулированный экзаменационный вопрос]
### Краткий ответ (30 сек)
...
### Развёрнутый ответ (3-5 мин)
1. Определение
2. Ключевые аспекты
3. Примеры из лекции
4. Связи с другими темами
### Возможные доп. вопросы преподавателя
- ...
```

### `outline` — План/каркас
Только заголовки и тезисы без полного текста.

## Workflow

1. Получить транскрипт + режим
2. Очистить: убрать ASR-артефакты, повторы, оговорки, шум
3. Восстановить структуру: определить подтемы по контексту
4. Извлечь термины, концепции, факты, формулы
5. Сгенерировать выход в формате режима
6. Проверить:
   - Все ли факты из транскрипта (не выдуманы)
   - Термины корректны (не искажены ASR)
   - Нет AI-паттернов в тексте
   - Кавычки: «ёлочки», тире: –

## Правила обработки транскрипта

1. **ASR-ошибки**: исправлять очевидные (эмпирический → эмпирический), помечать неочевидные `[ASR?]`
2. **Повторы**: убирать, оставляя смысл
3. **Оговорки**: убирать, если не несут смысла
4. **Числа и формулы**: восстанавливать по контексту, помечать `[уточнить]` если неоднозначно
5. **Имена/названия**: сохранять как в лекции, помечать `[имя?]` если неясно
6. **Не добавлять** внешние факты, которых нет в транскрипте

## Self-Check

- [ ] Все факты из транскрипта — нет выдуманных
- [ ] Термины не искажены ASR-ошибками
- [ ] Формат соответствует выбранному режиму
- [ ] Нет AI-паттернов (Rule 36)
- [ ] Кавычки «ёлочки», тире –
- [ ] Сохранена терминология курса (как говорит преподаватель, не «как в учебнике»)

## Gotchas

- ASR часто искажает термины: «регресси я» → «регрессия», «супервизированный» → «supervised» — восстанавливай по контексту.
- Преподаватель может ошибаться — не «исправляй» его в конспекте, но можешь отметить в `review` режиме.
- Не путай пересказ (narrative) с анализом (review) — это разные режимы с разной целью.
- Формат `exam_prep` требует формулировки вопросов — они должны быть реалистичными для данного курса.
